# Traveler artwork

`traveler.webp` is an original AI-generated character cutout made for this portfolio with the built-in image-generation tool. The final web asset is 683 × 1024 pixels with alpha, encoded as WebP. It is separate from the credited photographic environment plates in `/plates/PLATES.md`.

Prompt: A full-body original young male traveler with brown skin, slender teenage proportions, three-quarter back view, standing with a small red rolling suitcase. Navy hooded jacket, headphones, dark backpack and trousers, cream sneakers. Hybrid 3D/cel/painted feature-animation treatment: sculpted volumes, angular painted planes, hard shadows, sparse crosshatch and shadow halftone, imperfect paint texture, thin cyan and amber rim light, inky navy and burgundy. Low camera angle, believable cloth and weight, clean transparent silhouette. No existing character likeness, superhero suit, symbols, typography or watermark.
